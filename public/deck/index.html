III · the witness

Each printed line carries its own witness.

Σ codes of number and body · mod 256

“A match is evidence, never proof.”

43/43

line checksums matched the printed :rem on a real June 1984 page (vision-read; page withheld, rights)

Most printed lines end in a :rem checksum: the ASCII codes of the line number's digits and of the body, spaces counting zero, mod 256. Our implementation matched the printed sum on 43 of 43 lines of a real June 1984 page; the page itself is withheld (rights). A mod-256 sum collides easily, so a match is evidence, never proof, and the C64 must still run the line.

gate output · line 20 as OCR read it

REFUSED (R4.15): line 20 contains "™", which no C64 key types. The magazine's checksum is the sum of what the typist typed, so this cannot be the printed line; write the character the page shows (Gazette notation for control keys).

A Kiro Pre Tool Use hook runs this gate before apply_patch reaches the MCP server; a refusal exits 2 and the agent reads the reason verbatim. The trademark sign is the trap: its code, 8482, is 34 mod 256, the code of a quote, so the raw sum matches. The gate sums the line as written, then refuses any line holding a character no C64 key types, because the loader would drop it.

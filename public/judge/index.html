Three minutes with a listing that rose.

SYNTAX ERROR IN 20 is a Kiro agent that repairs the lines OCR misread in 1984 magazine type-in programs. It can change a line only through a gate that checks it against the checksum the magazine printed beside it, and a real C64 core then runs the program and decides the verdict.

08 · Honest limits

What it does not do, said before you find it.

  1. The live site is recorded playback. No Commodore ROM is hosted (rights), so nothing runs on a C64 in your browser there; the page says RECORDED PLAYBACK and the stamp says "as recorded". A clone does run the C64.
  2. The three runs on / are pages we typeset in the 1984 format with planted misprints, read by real OCR. The one real 1984 page the agent repaired is reported by counts only (rights).
  3. /scan does not run the agent (Kiro runs only in kiro-cli on the builder's machine; there is no hosted Kiro run) and leaves the fixing to you. On the real page tesseract.js misreads most lines: at 1600 px, 16 of the 83 lines it read matched their printed checksum (spike-P-ocr-live.json). Its CDN keeps a copy of the archive.org image for up to a day (and may serve a stale one for up to a week while it refreshes).
  4. No recorded run of the shipped agent contains a hook refusal. The agent checks each candidate with checksum_line before sending it, so the Pre Tool Use hook is a backstop: its exit-2 path is shown by the tests and the day-1 probe sessions, and the refusal on screen is Cheat.
  5. Headless, Kiro's Agent Stop hook forces one more turn per prompt, not a loop, so scripts/record-run.mjs resumes the session between cycles. In the 17 runs outside E3 it never had to.
  6. The video is older than this repo. Its receipts read 492 tests and 6 of 6 model runs; the figures here (520 tests + 1 expected fail, 12 of 12 model runs) are from the later code. Its description names three specs: the bugfix spec was written the next day.
  7. Small N: N=3 per eval case and N=2–3 per experiment arm, on one machine: directions, not rates.
  8. Kiro coverage: kiro-cli only, the Kiro IDE was not used. resurrect-loop tasks T2–T6 and c64-mcp-server task 8 are still open in their tasks.md.

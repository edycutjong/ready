REFUSED (R4.15): line 20 contains "™", which no C64 key types. The magazine's checksum is the sum of what the typist typed, so this cannot be the printed line; write the character the page shows (Gazette notation for control keys).

The ™ trap. OCR read the opening quote as ™ (code 8482, 34 mod 256: a quote). Fix only the M and a raw sum matches (159 = 159), yet the gate refuses: no C64 key types ™.

Questions a judge would ask.

Is the C64 on this page real?

Recorded from c64-ready@3.4.0's screen memory. No C64 ROM is served (rights), so the stamp says "as recorded"; the gate panel is live.

Can the agent cheat its way to IT LIVES?

Not by the shortcuts we tested: an emptied line, an untypeable character and a rewrite are refused, and a forced patch is never certified (eval cases 4 and 9, unit tests). A wrong line whose sum matches and runs would pass: results say consistent, not identical.

Does it work on a real 1984 page?

On the June 1984 Gazette's Random Number Test: TITLE-PATH RESURRECTED in 3 of 3 eval runs. In two earlier spike runs, 19 of 28 lines matched a vision-read reference exactly. The recordings are withheld (rights).

- The Agent Stop hook / runner check (`until-title.mjs`) is the ONE stop rule: RESURRECTED (computed contract), or only unfixable lines left, or a cap. The title alone is BOOTED — PARTIAL, never success.
- Terminal states from `contract.ts`: RESURRECTED / BOOTED — PARTIAL / NOT RESURRECTED. Every recorded run is replayable (REPLAY re-judges each attempt and re-runs each patch).
